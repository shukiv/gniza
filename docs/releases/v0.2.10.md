# v0.2.10

## Your customers can see their own backup history

The account tile had **Overview** and **Restore & download**. Neither
answered the question people open it to ask — *was my site backed up last
night* — so that question came to you instead.

**Logs** is the third tab. One account's own record: every backup taken of
it, and every recovery asked for from it.

The backup table says when each run happened, whether it worked, and what
is **not in this backup**. A run that stored everything except one
database reads as *Backed up, without everything* — not a success, not a
failure, because it is neither — and does not claim to be a restore point
for the whole account.

## What a customer is not shown

The reason something was left out. That line is command output: it names
the server's paths, the destination's address and the software that
failed. Only the thing itself crosses to the customer — `database
studio_wp`, never the `mysqldump` line under it, and there is a test that
fails if any of the rest arrives. A failed restore has reached the
customer as a sentence they can act on since the account socket existed;
backups now follow the same rule.

The server's own log is not there and will not be. That is what **Logs**
in WHM is for, behind the root-only socket.

## Three things the page has to get right

A **recycled username** has two customers' runs under it, and a run names
the databases it could not store. Runs are now judged against the identity
boundary that restores have always been judged against, so the new holder
of a name sees their own history and not the last customer's database
names.

A run is a **whole-account restore point** only if it stored the whole
account. Missing nothing is not enough: a schedule that excludes databases
misses nothing it was asked for. The row reads the same completeness
signal that termination safety reads.

A **partly successful** run stored everything and could not put it
everywhere. That reads as *Backed up to some destinations*, not as a hole
in the backup beside an empty list of missing things.
