# v0.3.1

## An account's application backups are not backed up again

Installatron and Softaculous write a compressed copy of the site and a
dump of its database under the account's home on every automatic update.
Each one is a fresh compression, so it deduplicates against almost
nothing, and what it holds is what the snapshot already holds directly
from the site's own files.

On one validation server that directory was 12 GiB of a 20 GiB account —
gigabytes of near-full ingest every night to store a second copy of files
restic reads where they lie.

It is left out of a DirectAdmin backup now, beside the account's own
backup directories, which were left out for the same reason.
