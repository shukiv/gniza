# v0.3.10

## Icons and the mark

Every icon on the pages is now from Lucide, inlined as before so a
page loads nothing from outside. Restore and Logs no longer share a
symbol: Restore is an archive being put back, Logs is a scroll. The
customer's pages take the same set, including the symbol beside each
kind of thing that can be restored.

The Gniza mark stands on the page in the primary colour, with no tile
behind it.
