# v0.3.20

## The weekly integrity check runs every week again

A check is recorded when it finishes, and the upkeep comes to the check once a
night, at about the hour the last one started. Held to a whole week, it was always
short by the length of the check and waited for the next night, so the weekly
check ran every eight days on almost every server. It now comes due half a day
short of a week. A new repository is still first checked a day after it was made.

## Download it as a file saves the recovery key under DirectAdmin

DirectAdmin puts its own page around whatever a plugin answers and drops the
plugin's headers, so the recovery key's download arrived as text laid out in the
page instead of a file. The page now carries the file and the browser saves it,
and saving it records the key as stored, as the download always did. With
JavaScript turned off the button still asks the server for the file.

## A compression library past a crash

github.com/klauspost/compress goes from v1.20.0 to v1.20.2, past GO-2026-6865: a
panic on frames of two blocks, reachable when a DirectAdmin backup is packed.
