# v0.3.7

## The terminal interface looks like one

The first screen an operator saw on a server with no panel was bare
text. Every screen of `gniza-agent -tui` is now the same frame: a title
bar with the server's name, tabs, one bordered panel, and a foot that
says what is running and what the keys do, in a palette that reads on a
light terminal and on a dark one.

The overview leads with the verdict and four cards: accounts,
destinations, next run, staging space. Tables light the whole of the
cursor's row and colour status words the same everywhere: green is
fine, amber wants a look, red wants an act. Forms are one line per
field with a lit edge on the one that has the focus, and a
confirmation and the recovery key are cards of their own.
