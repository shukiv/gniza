What a backup contains

Part of the accountHow it is stored
Home directory Backed up as files, in place — every site, every mailbox.
So a night that changed one file stores one file.
Databases One plain .sql dump per database.
Dumped by Gniza, not packed inside {{$.Panel}}'s archive: plain SQL deduplicates between nights, a compressed archive does not.
Settings, DNS, SSL, mail configuration {{$.Panel}}'s own account archive, with the home directory and databases left out of it.

Remove Gniza from this server

Stops the service and unregisters {{if $.Cpanel}}the WHM plugin, the cPanel hooks{{else}}the {{$.Panel}} plugin{{end}} and the account tile. This page goes with it. Backups already on their destinations are not touched, and neither is anything on this server outside Gniza — but nothing here will take backups afterwards.

/etc/gniza/master.key and /var/lib/gniza/state.db stay, so reinstalling comes back with the same destinations, schedules and history.

Or in a root shell: sh /usr/local/share/gniza/uninstall.sh
